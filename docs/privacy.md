# Privacy Policy

AutoChannel is a personal tool used only by its owner, Saran Vishakan, on his own YouTube channel.

- **What it accesses:** via Google OAuth, it uploads videos to the owner's own YouTube channel and reads that channel's analytics (views, watch time).
- **What it stores:** a refresh token, kept in the owner's private GitHub Actions secrets. Nothing else is collected.
- **Sharing:** no data is sold, shared or disclosed to anyone. No other users are involved.
- **Revoking:** access can be removed at any time at https://myaccount.google.com/permissions
